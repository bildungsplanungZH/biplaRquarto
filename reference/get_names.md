# Namen der verfügbaren Quarto-Vorlagen abrufen

Namen der verfügbaren Quarto-Vorlagen abrufen

## Usage

``` r
get_names()
```

## Value

character mit Namen der Vorlagen

## Examples

``` r
get_names()
#> [1] "biplaR-docx"     "biplaR-html"     "biplaR-pdf"      "biplaR-revealjs"
#> [5] "biplaR-typst"   
```
